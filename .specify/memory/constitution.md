# Meta-Oracle Constitution

## Core Principles

### I. The Economic Prime Directive
All operations MUST run on the GCP Free Tier within the `vindicta-warhammer` project only. No standing monthly costs for the base system. AI costs MUST be isolated via a "Gas Tank" model using Gemini models.

### II. Spec-Driven Methodology
No code without a Specification. Behavioral (BDD) and Technical (TDD) tests MUST fail before implementation begins. Red-Green-Refactor cycle strictly enforced.

### III. Council & Adversarial Protocol
Meta-Oracle implements adversarial debate between a 5-agent swarm to identify tactical predictions for competitive Warhammer. Personas MUST be dynamically selected for each session.

### IV. Mechanical Fidelity (Rule-Sage)
All mechanical claims MUST be verified by the Rule-Sage Auditor against competitive 10th Edition standards. Dice resolution MUST use CSPRNG with traceable `EntropyProof`.

### V. Async-First & Pipeline Efficiency
All I/O MUST be asynchronous. The data pipeline MUST use DuckDB for efficient multimodal ingestion and inference.

## Governance

This Constitution is the supreme authority for the Meta-Oracle codebase. All developments must be audited against these principles. Amendment requires an explicit `/speckit-constitution` update and version bump.
