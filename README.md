# Meta-Oracle

AI debate engine powering the 5-agent swarm for competitive Warhammer analysis.

## Overview

Meta-Oracle implements adversarial debate between AI agents to identify "sleeper" army lists and provide tactical predictions.

## Features

- **5-Agent Swarm**: Specialized debate participants
- **Council Protocol**: Dynamic persona selection
- **Rule-Sage Auditor**: Mechanical claim verification
- **DuckDB Ingestion**: Efficient data pipeline

## Installation

```bash
uv pip install git+https://github.com/vindicta-platform/Meta-Oracle.git
```
